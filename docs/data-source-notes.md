# 積金局公開資料核對筆記

更新日期：2026-08-13（香港時間）。

| 項目 | 官方觀察 | 專案採用方式 |
|---|---|---|
| 主要平台 | 積金局「強積金基金平台」基金資訊表 | `data/funds.json` 的唯一資料來源依據 |
| 基金數量 | 平台頁面顯示 382 隻成分基金、451 個基金等級 | 種子資料只擷取具完整欄位的代表性 80+ 隻基金 |
| 資料截至 | 基金資訊表與回報圖表標示 2026-07-31 | 檔案的 `as_of` 統一標示 `2026-07` |
| 回報 | 官方說明回報已扣除收費，屬淨回報 | 欄位以年率化 1 年、3 年、5 年百分比存放 |
| FER | 官方說明部分 FER 為上個財政期的過往資料 | 介面標記為基金開支比率（FER）並展示資料日期 |
| 可比性 | 官方提示保證基金及未分類基金特性未必相同，未必適合直接比較 | 排名僅在同一應用程式資產類別內計算，並在介面顯示免責聲明 |
| 使用限制 | 官方平台指出只可作非商業用途並註明積金局出處 | README 與頁尾均標註來源；不宣稱即時或自動更新 |
