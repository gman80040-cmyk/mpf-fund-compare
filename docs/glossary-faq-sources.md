# MPF 術語與常見問題：官方內容依據

本文件記錄「MPF 小詞典與常見問題」的撰寫邊界。頁面只解釋公開資料欄位及文件用途，不按個人情況建議基金、資產配置或轉換行動。

| 主題 | 採用的中立說明 | 官方依據 |
| --- | --- | --- |
| 年率化回報 | 多年期回報以複利效果換算為平均 12 個月回報，並非把累積回報直接除以年數。 | [MPF Fund Platform Glossary](https://mfp.mpfa.org.hk/eng/mpp_glossary.jsp) |
| 基金開支比率（FER） | FER 為基金開支相對基金規模的比率，以最近一個財政期計算；已刊載數字未必反映本財政期收費變動，少於兩年歷史的基金可不列示。 | [MPF Fund Platform Glossary](https://mfp.mpfa.org.hk/eng/mpp_glossary.jsp) |
| 風險級別／指標 | 平台風險級別以基金風險指標的波動性區間劃分；它是比較資料的一部分，仍應閱讀基金便覽的目標、持倉與收費。 | [MPF Fund Platform Glossary](https://mfp.mpfa.org.hk/eng/mpp_glossary.jsp) |
| 基金類別及同類比較 | 股票、債券、混合資產、保證、強積金保守及貨幣市場基金的特性不同；比較時應先確定類別及細分類。 | [MPF Fund Platform Glossary](https://mfp.mpfa.org.hk/eng/mpp_glossary.jsp) |
| 預設投資策略（DIS） | DIS 由核心累積基金及 65 歲後基金組成，涵蓋自動降低風險、費用上限及全球分散投資；兩者均不保本或保證回報。 | [MPFA: Default Investment Strategy](https://www.mpfa.org.hk/en/mpf-investment/portfolio/default-investment-strategy) |
| 閱讀回報、風險及收費 | 投委會建議把基金類型、風險、費用及表現一併閱讀；過往表現不代表未來表現，並可每半年或一年檢視一次。 | [IFEC: Five steps to choosing MPF funds](https://www.ifec.org.hk/web/en/young-adults/youth-investment/5-steps-mpf-funds.page) |

> 本頁與網站所有比較工具均只供資訊參考，不構成投資建議；遇有任何差異，以受託人、基金便覽及積金局的最新資料為準。
