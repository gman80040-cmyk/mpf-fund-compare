# MPF 新手傻瓜包：內容依據與編寫邊界

本頁記錄網站「新手傻瓜包」的公開資料依據。教學將只說明強積金的基本概念、文件閱讀方式及使用本站比較工具的步驟；不會按用戶的年齡、資產、收入或風險偏好推薦個別基金。

| 主題 | 官方來源 | 實作重點 |
| --- | --- | --- |
| 新會員資料 | [MPFA：Made-easy guide book](https://www.mpfa.org.hk/en/info-centre/publications-articles/mpfa-articles/2024_9_25) | 說明受託人須為新成員提供「傻瓜包」及 Key Scheme Information Document（KSID）；KSID 概覽基金選擇、收費、風險與行政程序。 |
| 基金比較步驟 | [投委會：揀選強積金基金 5 個步驟](https://www.ifec.org.hk/web/tc/young-adults/youth-investment/5-steps-mpf-funds.page) | 教導先了解基金類型及資產配置，再比較風險、收費與長期表現；不單憑往績選擇。 |
| 預設投資策略 | [MPFA：Default Investment Strategy](https://www.mpfa.org.hk/en/mpf-investment/portfolio/default-investment-strategy) | 說明 DIS 使用核心累積基金及 65 歲後基金、包含自動降低風險、費用上限及環球分散投資；兩者均非保本或保證回報。 |

> 更新教學內容時，應先核對以上官方來源及發布日期。數據或制度如有變動，以積金局與相關官方文件為準。

## 教學寫作原則

1. 使用「比較」「核對」「考慮」等中立措辭，避免「應買」「最好」或個人化推薦。
2. 每個有關回報的段落，必須同時提示：往績不代表將來表現。
3. 每個有關費用、風險或 DIS 的段落，必須引導讀者查閱 KSID、基金便覽或受託人文件。
4. 教學結尾必須保留網站雙語免責聲明：本工具僅供資訊參考，不構成投資建議。
